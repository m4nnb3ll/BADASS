# Steps to install gns3
0- Install busybox-static (in case of debian)
1- Create a virtual env
2- Install PyQt5 package
3- Install ubridge (check gns3 repo)
4- Download the source for both gns3-server and gns3-gui (2.2.52)
(Note: Used ubridge version is 0.9.18, but try the newest)
5- Follow install instructions
